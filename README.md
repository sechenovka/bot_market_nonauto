# MarketBot — ИИ‑ассистент для поиска бизнесов с рутинными проблемами

Telegram‑бот, который сам находит ИП, малый бизнес и активных частных продавцов в России, анализирует их рутинные трудности с помощью ИИ DeepSeek и публикует всё в ваш канал. Никаких платных библиотек — только бесплатные API и этичный (легальный) парсинг.

## 🔍 Что он умеет (изюминки)

- **Поиск по 4 источникам:**
  - **Дадата** (официальные ИП/юрлица) — легально, по API.
  - **ВКонтакте** — посты с коммерческими ключевыми словами.
  - **Telegram‑каналы** — через Telethon (публичные каналы).
  - **Avito** — товары с отзывами (признак реальных продаж).
- **Всё проходит через DeepSeek:** каждый найденный объект анализируется ИИ, который определяет сферу деятельности, технологический уровень и 3‑5 типичных рутинных проблем.
- **Умная фильтрация:** технологически продвинутые компании автоматически игнорируются — вы не тратите время на тех, кто уже всё автоматизировал.
- **Автопостинг в Telegram‑канал:** красивое сообщение с названием, ссылкой, контактами и списком проблем.
- **Локальная база данных:** SQLite через Prisma ORM, каждой записи присваивается UUID, исключаются дубли.
- **Работает полностью бесплатно (free tier):**
  - DeepSeek API (бесплатный ключ)
  - Dadata API (1000 запросов/день)
  - VK API (ключ Standalone‑приложения)
  - Telethon (ваш номер телефона только для авторизации, не для бота)
  - Avito — публичный JSON‑эндпоинт, соблюдается Crawl‑delay.
