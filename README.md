# MarketBot – ИИ‑ассистент для поиска бизнесов с рутинными проблемами (v2.0)

Telegram‑бот, который автоматически находит ИП, малый бизнес и активных частных продавцов через **легальные источники**, анализирует их типичные проблемы с помощью **DeepSeek** и публикует всё в ваш канал `market_bot`.

## 🔥 Возможности (изюминки)

- **3 легальных источника данных:**
  - **Dadata** – официальные ИП и юрлица РФ (API).
  - **DataNewton** – дополнительный источник организаций (API).
  - **Avito (через Яндекс.Поиск)** – популярные товары с активностью (легальный поиск).
- **Сквозной ИИ‑анализ (DeepSeek):** каждый найденный объект прогоняется через языковую модель, которая определяет:
  - Сферу деятельности
  - Технологический уровень (развит / не развит)
  - 3–5 рутинных проблем (кассовые разрывы, персонал, документооборот и т.д.)
- **Автоматическая фильтрация:** IT‑компании и технологически продвинутые бизнесы **игнорируются** – вы не тратите время на тех, кто уже всё автоматизировал.
- **Публикация в Telegram‑канал:** каждое найденное ИП / объявление отправляется в ваш канал с подробным описанием, списком проблем и контактами.
- **Локальная база данных:** SQLite через Prisma ORM. У каждой записи уникальный UUID, исключены дубли.
- **100% легально:**
  - Никакого нелегального парсинга – только официальные API и этичный поиск.
  - Персональные данные **не хранятся** – только обезличенные заголовки, ссылки и результаты анализа.
  - Соблюдаются лимиты запросов и условия использования сервисов.

## ⚙️ Требования

- **Python 3.11+**
- Установленный менеджер пакетов `pip`
- **Токен Telegram‑бота** (получить у [@BotFather](https://t.me/BotFather))
- **API‑ключ DeepSeek** ([platform.deepseek.com](https://platform.deepseek.com))
- **API‑ключ Dadata** ([dadata.ru](https://dadata.ru/api))
- **API‑ключ DataNewton** (получить в личном кабинете сервиса)
- **Yandex Cloud аккаунт** с API‑ключом для Поиска (подробности ниже)
- **Telegram‑канал**, куда бот будет писать (ID канала узнать через [@getidsbot](https://t.me/getidsbot))

## 🔑 Получение ключей API

### 1. Telegram‑бот
- Напишите [@BotFather](https://t.me/BotFather), отправьте `/newbot`, следуйте инструкциям. Получите токен и сохраните в `BOT_TOKEN`.

### 2. DeepSeek
- Зарегистрируйтесь на [platform.deepseek.com](https://platform.deepseek.com), перейдите в раздел «API Keys», создайте ключ.

### 3. Dadata
- Зарегистрируйтесь на [dadata.ru](https://dadata.ru), подтвердите email. Ключ и секретный ключ появятся в личном кабинете.

### 4. DataNewton
- Получите ключ в личном кабинете сервиса (уточните URL API в документации DataNewton).

### 5. ID Telegram‑канала
- Добавьте бота в канал, назначьте администратором.
- Отправьте в канал любое сообщение.
- Перешлите это сообщение боту [@getidsbot](https://t.me/getidsbot) — он вернёт ID (обычно начинается с `-100`).

### 6. Яндекс.Поиск (для Avito)
1. Создайте платёжный аккаунт в [Yandex Cloud](https://console.cloud.yandex.ru). Карта нужна только для верификации (деньги не спишут без превышения бесплатных лимитов).
2. Создайте сервисный аккаунт с ролью **`search-api.executor`** (вкладка «Сервисные роли»).
3. Внутри сервисного аккаунта создайте **API‑ключ** — скопируйте его.
4. В верхней части консоли выберите вкладку **«default»** и скопируйте **Идентификатор каталога** (начинается с `b1g`).
5. Вставьте эти значения в `.env` как `YANDEX_API_KEY` и `YANDEX_FOLDER_ID`.
